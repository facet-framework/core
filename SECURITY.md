# Security reports for FACET

Report a suspected vulnerability through this repository's GitHub **Security →
Report a vulnerability** form when private reporting is available. If the form is
unavailable, email <hello@facet-framework.com> with a short description and no
exploit steps, sensitive files or credentials in the first message. Discuss the
technical details privately.

Include the affected release, platform, a minimal reproduction and the observed
impact. Use synthetic records and remove access tokens and private source paths.
A proposed fix is welcome but is not required for a report.

Record and plugin content can be untrusted. Running a test, command-line agent or
installed plugin may execute code with your local account's permissions. This
software does not provide an operating-system sandbox for that code. Avoid
running commands or plugins from sources you do not trust.

Security fixes are identified in tagged release notes. Reports should identify
the exact version; maintainers may ask you to check a current release while
investigating. No response-time or support-period guarantee is implied.
