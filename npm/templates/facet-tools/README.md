# facet-tools

Reserved for further FACET products. None is available through npm yet, so
this package runs no product command today.

```sh
npx facet-tools --help
npx facet-tools --version
```

This package provides only the `facet-tools` command, never `facet`. The
`facet` command belongs to `facet-framework`, the FACET Core command line, so
both packages can be installed globally side by side.

Requires Node.js 18 or later.
