# facet-tools

Reserved for further FACET products; none is available through npm yet. The
FACET command line itself is the `facet-framework` package.

```sh
npx facet-framework@@@VERSION@@ init
```

## About this package

This package provides only the `facet-tools` command (`--help`, `--version`),
never `facet`, so it can be installed globally beside `facet-framework`.
